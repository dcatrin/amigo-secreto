Desafio Alura Latam
- Este proyecto llamado "Amigo Secreto" permite sumar nombres a una lista para luego seleccionar un nombre como amigo secreto.
- En este caso, hay una validación de campo en blanco y nombre repetido (este control no aplica si el nombre tiene alguna diferencia entre mayuscula y minusculas)
- Se utilizó h2 para alertar al usuario de algo faltante o incorrecto.
